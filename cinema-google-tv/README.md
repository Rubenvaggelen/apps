# The One cinema for Android TV and Google TV

Dedicated TV package com.theone.cinema.tv. Based on the latest phone app, with a landscape layout, approved icon and 320x180 launcher banner, larger poster captions and explicit D-pad focus routes. English defaults, multilingual source/audio choice, background language selection, both existing sources and native playback remain enabled. Cinema keeps XXX separate; Series merges season and episode variants.

CI runs the preserved unit tests and native remote navigation/video/pause/play tests on an Android TV system image. Permanent owner signing identity verified; personal APK artifacts encrypted. Real streams are tested on the owner's Chromecast/TV.
