THE ONE - FANCY HOME ICONS

Deze patch vervangt alleen de iconen op het home-dashboard.
De bestaande ic_tile_parking / ic_tile_household resources blijven bestaan voor Android-notificaties.

Vanuit de root van je repository:
  python3 the-one-fancy-icons/apply-fancy-icons.py
  git add app/src/main
  git commit -m "Nieuwe luxe home icoontjes"
  git push
