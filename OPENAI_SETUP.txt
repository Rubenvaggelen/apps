THE ONE - OpenAI instellen

Deze versie gebruikt OpenAI voor:
- Vraag het
- Recepten
- volledige transcriptie van gesproken WhatsApp-antwoorden vanuit The One Car

GitHub instelling (eenmalig):
1. Maak een OpenAI API key in het OpenAI API-platform.
2. Open je GitHub repository -> Settings -> Secrets and variables -> Actions.
3. Maak een nieuwe Repository secret met exact deze naam:
   OPENAI_API_KEY
4. Plak je OpenAI API key als value en sla op.
5. Push daarna deze projectversie. De workflow injecteert de key alleen tijdens de build.

Let op: ChatGPT-abonnement en OpenAI API-facturering zijn aparte producten.
