# The One Studio
Part of The One family. Eigen DAW (muziekstudio) in de browser, versie 1.

## Starten
Open `index.html` in Chrome of Edge. Voor microfoon en MIDI-keyboard: open via http(s) (bijv. GitHub Pages) of lokaal bestand in Chrome.

## Functies v1
- Arrangement: sporen, clips slepen/inkorten, liniaal, zoom, raster, loop (sleep over liniaal)
- Audiosporen: importeren / slepen, microfoonopname, splitsen, omkeren, normaliseren
- Synthsporen: pianorol, 5 golfvormen, filter, envelope, LFO-modulator
- Drumsporen: 16-stappen sequencer, 6 geluiden, willekeurig patroon
- Mixer: 3-bands EQ, galm/echo-sends, pan, fader, meters, mute/solo, master-limiter
- Live spelen met toetsenbord (A t/m K, Z/X octaaf) of MIDI-keyboard
- Metronoom, ongedaan maken (Ctrl+Z), automatisch opslaan (incl. audio in IndexedDB)
- Mix exporteren als WAV (in zip), project opslaan/openen als JSON

## Sneltoetsen
Spatie afspelen/pauze, R opnemen, L loop, M metronoom, Home naar begin,
Delete clip verwijderen, Ctrl+D dupliceren, Ctrl+Z ongedaan maken.
