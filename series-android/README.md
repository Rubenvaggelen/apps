# The One Series Android

Independent phone app, package com.theone.series, version 1.0.0. Only series catalogs are loaded. The two existing sources merge by provider TV identifiers or matching titles; English variants and audio tracks are preferred. Seasons and episode numbers merge with alternate sources as playback backups. Approved stacked-screen Series branding. Permanent owner signing identity verified by CI; personal release artifacts encrypted for owner download. Secondary account remains on device and is never configured on the owner relay.

Validation: catalog/quality/language and artwork unit tests, episode season/number/grouping tests, phone emulator search → seasons → episode → native video first frame. Real provider playback is tested on the owner's phone.
