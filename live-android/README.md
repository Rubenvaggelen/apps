# The One TV

Personal Android TV and Google TV app. Directly merges the two configured live channel catalogs, groups duplicate quality/source variants, orders Netherlands → United States → England → remaining countries, and keeps alternate streams for fallback. Supports a remote, country filter, favorites, recent channels and native HLS/TS playback. Live channels are separate from film/series apps. Private provider configuration is restored only during owner-signed builds; artifacts are encrypted.
